## 📌 Descripción
Este proyecto es una página de contacto hecha con HTML y CSS. Contiene un ícono, un título, un texto y un formulario donde el usuario puede escribir su nombre, correo, seleccionar opciones en menús desplegables y enviar un mensaje. El diseño es ordenado y se adapta a diferentes tamaños de pantalla.
