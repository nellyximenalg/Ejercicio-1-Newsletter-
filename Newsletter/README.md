## 📌 Descripción
Este proyecto es una página web hecha con HTML y CSS que permite a los usuarios suscribirse a un Newsletter. La página tiene un ícono, un texto, un campo para escribir el correo electrónico y un botón para enviarlo. El diseño es simple y ordenado, con buena separación entre los elementos.
