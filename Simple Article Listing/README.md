## 📌 Descripción
Este proyecto es una página web hecha con HTML y CSS que muestra un listado de artículos. Cada artículo contiene una imagen, un título y una fecha de publicación. El diseño se realizó usando Flexbox para acomodar los elementos de forma ordenada y adaptable a diferentes tamaños de pantalla.

## 📝 Reflexión
En este proyecto aprendí a usar la etiqueta article para organizar contenido y a aplicar Flexbox para alinear imágenes y texto. También practiqué cómo dar estilo con CSS usando tamaños, márgenes y tipografía. Tuve algunas dificultades al acomodar los elementos, pero las resolví ajustando el diseño con Flexbox y los márgenes.
